# Madhav Store Sales Analysis Dashboard

An interactive retail sales and profitability dashboard built with **Microsoft Power BI**.

## Project Overview

This project explores retail sales performance through an interactive report. It brings key business metrics and category-level trends into one place to support performance monitoring and analysis.

## Dashboard Highlights

- KPI cards for **Sales Amount**, **Profit**, **Quantity**, and **Average Order Value**
- Monthly profit trend analysis
- Profit analysis by product sub-category
- Sales distribution by category
- Payment-mode distribution
- Customer and state-level sales analysis
- Interactive **Quarter** and **State** filters

## Tools & Features

- Microsoft Power BI Desktop
- Interactive report visuals
- KPI cards
- Slicers and filters
- Retail sales and profitability analysis

## Project File

Open `Madhav-Store-Sales-Dashboard.pbix` in **Power BI Desktop** to explore the report and interact with its filters.

## How to View

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Use the Quarter and State filters to explore the report.
4. Select chart elements to cross-filter related visuals.

## Business Questions Explored

- How does profit change month by month?
- Which product sub-categories contribute to profit?
- How are sales distributed across product categories?
- Which payment modes are used by customers?
- How do sales and performance vary by state?
